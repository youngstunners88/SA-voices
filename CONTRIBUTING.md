# Contributing to SA Voices

Thank you for your interest in contributing to SA Voices! This document provides guidelines for contributing to this project.

## 🌟 Ways to Contribute

- **Report bugs**: Open an issue with bug details
- **Suggest features**: Open an issue with feature request
- **Write code**: Submit a pull request
- **Improve documentation**: Fix typos, clarify explanations
- **Add language support**: Help improve voice quality for SA languages
- **Test**: Try the system and report issues

## 🚀 Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/SA-voices.git`
3. Set up development environment:
   ```bash
   cd SA-voices
   ./scripts/setup.sh
   source venv/bin/activate
   ```
4. Create a branch: `git checkout -b feature/your-feature`

## 📝 Code Style

- Follow PEP 8 for Python code
- Use type hints where appropriate
- Write docstrings for functions and classes
- Keep functions focused and small
- Add tests for new features

## 🧪 Testing

```bash
# Run all tests
pytest

# Run with coverage
pytest --cov=src

# Run specific test file
pytest tests/test_tts.py
```

## 📋 Pull Request Process

1. Update documentation for any changed functionality
2. Add tests for new code
3. Ensure all tests pass
4. Update CHANGELOG.md if applicable
5. Submit PR with clear description

## 🌍 Language Contributions

To improve voice quality for a specific South African language:

1. Record or collect high-quality audio samples
2. Verify transcription accuracy
3. Test with native speakers
4. Submit audio dataset or model improvements
